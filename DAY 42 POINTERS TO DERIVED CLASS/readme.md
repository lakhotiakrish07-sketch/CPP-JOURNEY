# Day 42 - C++ Pointer to Derived Class

## 🚀 Topic

Pointer to Derived Class in C++

## 📌 Description

This project demonstrates how pointers behave with inheritance in C++ and the difference between base class pointers and derived class pointers.

## 🧠 Concepts Used

* Classes & Objects  
* Inheritance  
* Pointer to Derived Class  
* Pointer to Base Class  
* Dynamic Memory Allocation  

## 💻 Implementation

### 1. Animal System
* Used derived pointer to access both base and derived functions

### 2. Student System
* Used derived pointer for full access  
* Used base pointer to observe restricted access  

### 3. Shape System
* Compared derived pointer vs base pointer behavior  

## 📷 Output

Displays how different pointers access class members and shows the restriction of base class pointers.
