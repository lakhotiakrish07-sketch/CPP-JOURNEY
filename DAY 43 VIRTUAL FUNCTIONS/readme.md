# Day 43 - C++ Virtual Functions

## 🚀 Topic

Virtual Functions in C++

## 📌 Description

This project demonstrates how virtual functions enable runtime polymorphism in C++ and how function calls are resolved based on object type.

## 🧠 Concepts Used

* Classes & Objects  
* Inheritance  
* Virtual Functions  
* Function Overriding  
* Runtime Polymorphism  

## 💻 Implementation

### 1. Employee System
* Used virtual function to return different salaries for FullTime and Intern  

### 2. Shape System
* Calculated area using base pointer with different derived classes  

### 3. Animal System
* Used base class pointers and loop to demonstrate polymorphism  

## 📷 Output

Displays different outputs for the same function call depending on object type.

## 📈 Progress

Solved 3 problems using virtual functions and polymorphism.

## 🔥 Learning Outcome

Understood how virtual functions enable runtime decision making and how base class pointers can call derived class functions.
