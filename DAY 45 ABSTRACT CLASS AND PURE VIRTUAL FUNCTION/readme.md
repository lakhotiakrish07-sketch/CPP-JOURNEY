# Day 45 - C++ Abstract Base Class & Pure Virtual Function

## 🚀 Topic

Abstract Base Class and Pure Virtual Functions in C++

## 📌 Description

This project demonstrates how abstract base classes and pure virtual functions are used to achieve abstraction and enforce function implementation in derived classes.

## 🧠 Concepts Used

* Abstract Base Class  
* Pure Virtual Function  
* Inheritance  
* Function Overriding  
* Runtime Polymorphism  
* Base Class Pointer  

## 💻 Implementation

### 1. Shape Area System
* Created abstract class `Shape`  
* Implemented `area()` in Rectangle and Circle  

### 2. Animal Sound System
* Created abstract class `Animal`  
* Implemented `sound()` in Dog and Cat  

### 3. Employee Salary System
* Created abstract class `Employee`  
* Implemented `salary()` in FullTime and Intern  

## 📷 Output

Displays different outputs for derived class implementations using base class pointers.

## 📈 Progress

Solved 3 problems using abstract classes and pure virtual functions.

## 🔥 Learning Outcome

Understood how abstract classes act as blueprints and how pure virtual functions force derived classes to implement required behavior.
