📌 Project Description

This is a simple Student Management System made using C++ without using STL or File Handling.

The project allows users to:

Add student records
Display all students
Search student by ID
Update student marks

It is a menu-driven console application suitable for beginners and practical exams.

🚀 Features
Add Student
Display Students
Search Student by ID
Update Marks
Simple Menu Interface
