# Day 46 - C++ Templates

## 🚀 Topic

Class Templates, Parameterized Templates and Default Templates in C++

## 📌 Description

This project demonstrates how templates help in creating generic and reusable classes for different data types in C++.

## 🧠 Concepts Used

* Class Templates  
* Parameterized Templates  
* Default Template Arguments  
* Generic Programming  
* Classes & Objects  

## 💻 Implementation

### 1. Calculator Template
* Created generic calculator class  
* Performed addition using different data types  

### 2. Parameterized Template
* Used multiple template parameters  
* Stored different types of data in same class  

### 3. Default Template
* Used default data type in template  
* Created objects with and without specifying type  

## 📷 Output

Displays operations and values using different template data types.

## 📈 Progress

Solved problems using class templates and generic programming.

## 🔥 Learning Outcome

Understood how templates reduce code duplication and make programs flexible for multiple data types.
